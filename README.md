# 📦 ผู้ช่วยคลังพัสดุ (Warehouse Assistant PWA)

แอปมือถือแบบ **แชทบอท** สำหรับค้นหา **รหัสพัสดุ** จากชื่อสินค้า เพื่อนำไปใช้เบิกของ
พร้อมระบบ **เดาคำเมื่อพิมพ์ผิด** และ **โหมดผู้ดูแล** สำหรับอัปเดตสต็อกผ่านไฟล์ Excel/CSV

ติดตั้งลงมือถือได้เหมือนแอปจริง (PWA) และใช้งาน **ออฟไลน์** ได้

---

## ✨ ฟีเจอร์

- 💬 UI แชทบอท พิมพ์ชื่อสินค้า → ได้รหัสพัสดุ + ปุ่มคัดลอก
- 🧠 เดาคำอัตโนมัติเมื่อสะกดผิด (fuzzy search)
- 📊 แสดงหมวดหมู่ / หน่วยนับ / สถานะสต็อก
- 🔐 โหมดผู้ดูแล (PIN: **1234**)
  - อัปโหลด **Excel/CSV** เพื่ออัปเดตสต็อก หรือเพิ่มรายการใหม่
  - โหมด "แทนที่จำนวน" และ "บวกเพิ่มจำนวน"
  - แก้จำนวนทีละรายการ / ดาวน์โหลดเทมเพลต / ส่งออกข้อมูล
- 💾 บันทึกข้อมูลถาวรในเครื่อง (localStorage)
- 📱 ติดตั้งเป็นแอป + ใช้งานออฟไลน์ (Service Worker)

---

## 🚀 วิธีนำขึ้น GitHub Pages

1. สร้าง repository ใหม่บน GitHub (เช่น `warehouse-app`)
2. อัปโหลด **ทุกไฟล์ในโฟลเดอร์นี้** ขึ้น repo (ลากวางในหน้าเว็บ GitHub ได้เลย)
3. ไปที่ **Settings → Pages**
4. หัวข้อ **Build and deployment → Source** เลือก **Deploy from a branch**
5. เลือก branch `main` โฟลเดอร์ `/ (root)` แล้วกด **Save**
6. รอสักครู่ จะได้ลิงก์รูปแบบ `https://<username>.github.io/warehouse-app/`

> ⚠️ ต้องมีไฟล์ครบทุกไฟล์ โดยเฉพาะ `index.html`, `manifest.webmanifest`, `sw.js`, `xlsx.full.min.js` และไฟล์ไอคอน

---

## 📲 วิธีติดตั้งลงมือถือ

**Android (Chrome):** เปิดลิงก์ → เมนู ⋮ → **"ติดตั้งแอป / เพิ่มไปยังหน้าจอหลัก"**
(หรือแตะปุ่ม ⬇️ ที่มุมบนของแอป)

**iPhone (Safari):** เปิดลิงก์ → ปุ่มแชร์ ⬆️ → **"เพิ่มไปยังหน้าจอโฮม"**

จะได้ไอคอนแอปเปิดแบบเต็มจอเหมือนแอปที่ติดตั้งจริง

---

## 📋 รูปแบบไฟล์นำเข้า (คอลัมน์)

รองรับหัวคอลัมน์ทั้งภาษาไทยและอังกฤษ:

| รหัสพัสดุ | ชื่อพัสดุ | หมวดหมู่ | หน่วยนับ | จำนวน | คำค้นหา |
|-----------|-----------|----------|----------|-------|---------|
| MT-1011 | ไขควงแฉก 4 นิ้ว | ฮาร์ดแวร์ | อัน | 25 | ไขควง\|screwdriver |

- จับคู่ด้วย **รหัสพัสดุ** — มีอยู่แล้ว = อัปเดต, ยังไม่มี = เพิ่มใหม่
- คอลัมน์ **คำค้นหา** ใส่คำพ้อง/คำสะกดผิด คั่นด้วย `|`

## 🗂️ ไฟล์ในโปรเจกต์

| ไฟล์ | หน้าที่ |
|------|---------|
| `index.html` | ตัวแอปหลัก |
| `manifest.webmanifest` | ข้อมูลแอปสำหรับติดตั้ง (PWA) |
| `sw.js` | Service Worker (ออฟไลน์) |
| `xlsx.full.min.js` | ตัวอ่านไฟล์ Excel (ฝังในตัว) |
| `icon-*.png`, `apple-touch-icon.png` | ไอคอนแอป |
| `.nojekyll` | ให้ GitHub Pages เสิร์ฟไฟล์ตรง ๆ |
