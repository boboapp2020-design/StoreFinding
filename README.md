# 📦 ผู้ช่วยคลังพัสดุ (Warehouse Assistant PWA)

แอปมือถือแบบ **แชทบอท** สำหรับค้นหา **รหัสพัสดุ** จากชื่อสินค้า เพื่อนำไปใช้เบิกของ
พร้อมระบบ **เดาคำเมื่อพิมพ์ผิด** และ **โหมดผู้ดูแล** สำหรับอัปเดตสต็อกผ่านไฟล์ Excel/CSV

ติดตั้งลงมือถือได้เหมือนแอปจริง (PWA) และใช้งาน **ออฟไลน์** ได้

---

## ✨ ฟีเจอร์

- 💬 UI แชทบอท พิมพ์ชื่อสินค้า → ได้รหัสพัสดุ + ปุ่มคัดลอก
- 🧠 เดาคำอัตโนมัติเมื่อสะกดผิด (fuzzy search)
- 📊 แสดงหมวดหมู่ / หน่วยนับ / สถานะสต็อก
- 🔐 โหมดผู้ดูแล (PIN: **1234**)
  - อัปโหลด **Excel/CSV** เพื่ออัปเดตสต็อก หรือเพิ่มรายการใหม่
  - โหมด "แทนที่จำนวน" และ "บวกเพิ่มจำนวน"
  - แก้จำนวนทีละรายการ / ดาวน์โหลดเทมเพลต / ส่งออกข้อมูล
- 💾 บันทึกข้อมูลถาวรในเครื่อง (localStorage)
- 📱 ติดตั้งเป็นแอป + ใช้งานออฟไลน์ (Service Worker)

---

## 🚀 วิธีนำขึ้น GitHub Pages

1. สร้าง repository ใหม่บน GitHub (เช่น `warehouse-app`)
2. อัปโหลด **ทุกไฟล์ในโฟลเดอร์นี้** ขึ้น repo (ลากวางในหน้าเว็บ GitHub ได้เลย)
3. ไปที่ **Settings → Pages**
4. หัวข้อ **Build and deployment → Source** เลือก **Deploy from a branch**
5. เลือก branch `main` โฟลเดอร์ `/ (root)` แล้วกด **Save**
6. รอสักครู่ จะได้ลิงก์รูปแบบ `https://<username>.github.io/warehouse-app/`

> ⚠️ ต้องมีไฟล์ครบทุกไฟล์ โดยเฉพาะ `index.html`, `manifest.webmanifest`, `sw.js`, `xlsx.full.min.js` และไฟล์ไอคอน

## 📲 วิธีติดตั้งลงมือถือ

**Android (Chrome):** เปิดลิงก์ → เมนู ⋮ → **"ติดตั้งแอป / เพิ่มไปยังหน้าจอหลัก"**
(หรือแตะปุ่ม ⬇️ ที่มุมบนของแอป)

**iPhone (Safari):** เปิดลิงก์ → ปุ่มแชร์ ⬆️ → **"เพิ่มไปยังหน้าจอโฮม"**

จะได้ไอคอนแอปเปิดแบบเต็มจอเหมือนแอปที่ติดตั้งจริง

## ☁️ ฐานข้อมูลจริงผ่าน Google Sheet (40,000+ รายการ)

รองรับข้อมูล Material Master (SAP) จำนวนมาก โดยเก็บใน Google Sheet และ **ค้นหาฝั่งเซิร์ฟเวอร์**
(Apps Script) — แอปมือถือไม่ต้องโหลดข้อมูลทั้งหมด จึงเบาและเปิดเร็ว

### 🛡️ ทนต่อไฟล์ที่ "คอลัมน์ไม่ตรงกันในแต่ละรอบ"

ไฟล์ export แต่ละรอบมักมีคอลัมน์ไม่เท่ากัน/สลับลำดับ (เช่น 9 / 10 / 13 คอลัมน์)
ระบบแก้ปัญหานี้ด้วยการ **จับคู่ข้อมูลจากชื่อหัวคอลัมน์ ไม่ใช่ตำแหน่ง**:

- บังคับแค่ **Material** + **Material Description** เท่านั้น ที่เหลือ optional
- คอลัมน์แปลกปลอม (เช่น Value Unrestricted, Val. in Trans.) → **ข้ามอัตโนมัติ**
- รองรับชื่อหัวทั้งไทย/อังกฤษ/SAP (แก้ไข/เพิ่มได้ที่ตัวแปร `ALIASES` ใน `Code.gs`)
- ไม่ว่าไฟล์จะมีคอลัมน์กี่คอลัมน์หรือเรียงแบบใด **ข้อมูลไม่เพี้ยน**

| ฟิลด์ | จับคู่กับหัวคอลัมน์ |
|---|---|
| code (รหัส) | Material, รหัสพัสดุ, MATNR |
| name (ชื่อ) | Material Description, ชื่อพัสดุ |
| unit (หน่วย) | Base Unit of Measure, หน่วยนับ |
| qty (คงเหลือ) | Unrestricted, จำนวน, คงเหลือ |
| group (หมวด) | Material Group, หมวดหมู่ |
| plant / โรงงาน | Plant / Name 1 |
| ที่จัดเก็บ | Storage Location / Descr. of Storage Loc. |

### ตั้งค่า (ทำครั้งเดียว)

1. **นำเข้าข้อมูล:** Google Sheet → **File → Import → Upload** เลือกไฟล์
   `MLStoreFinding-xx.xlsx` → **Import location: "Replace current sheet"**
   (ให้ชีตชื่อ **`Data`** — ไฟล์ .xlsx ของคุณใช้ชื่อชีต Data อยู่แล้ว)
2. **Extensions → Apps Script** → วางเนื้อหาไฟล์ **`Code.gs`** ทั้งหมด → บันทึก
3. รีเฟรช Sheet → เมนู **📦 คลังพัสดุ → ตรวจสอบคอลัมน์ที่ตรวจจับได้** เพื่อยืนยัน mapping
4. Apps Script → **Deploy → New deployment → Web app**
   - Execute as: **Me** · Who has access: **Anyone** ← *สำคัญ*
   - คัดลอก **Web app URL** (ลงท้าย `/exec`)
5. เปิดแอป → ⚙️ → PIN **1234** → **🔗 เชื่อมต่อ Google Sheet** → วาง URL →
   **บันทึก URL** → **🔌 ทดสอบเชื่อมต่อ**

> 🔁 แก้ `Code.gs` ภายหลัง ต้อง **Deploy → Manage deployments → New version** ทุกครั้ง

### การทำงาน

- **ผู้ใช้ค้นหา** → แอปส่งคำค้นไปที่ Apps Script → ค้นหา + เดาคำในข้อมูลจริง → ส่งผลกลับ
- **แอดมินอัปเดตสต็อก** → อัปโหลดไฟล์ในแอป → **upsert** เข้า Sheet (จับคู่ด้วยรหัส ปลอดภัยกับข้อมูลเดิม)
- **อัปเดตชุดใหญ่** → แนะนำ Import เข้าชีตโดยตรง (เร็วกว่าอัปโหลดผ่านแอป)
- **ยังไม่ใส่ URL** → แอปใช้ข้อมูลตัวอย่าง 10 รายการในเครื่อง (ออฟไลน์) ได้ตามปกติ

> ⏱️ การค้นหาแต่ละครั้งใช้เวลา ~2-3 วินาที (เซิร์ฟเวอร์สแกนข้อมูลทั้งหมด) เป็นเรื่องปกติของข้อมูลหลักหมื่นแถว

## 📋 รูปแบบไฟล์อัปโหลด (อัปเดตสต็อกผ่านแอป)

จับคู่ด้วยชื่อหัวคอลัมน์ (ไทย/อังกฤษ/SAP) ไม่ต้องเรียงตามลำดับ:

| Material | Material Description | Unrestricted | Base Unit of Measure |
|---|---|---|---|
| 1000000000000013 | ตะกรับเตา SMT17 | 5 | EA |

> จับคู่ด้วย **Material (รหัส)** — มีอยู่แล้ว = อัปเดต, ยังไม่มี = เพิ่มใหม่

- จับคู่ด้วย **รหัสพัสดุ** — มีอยู่แล้ว = อัปเดต, ยังไม่มี = เพิ่มใหม่
- คอลัมน์ **คำค้นหา** ใส่คำพ้อง/คำสะกดผิด คั่นด้วย `|`
